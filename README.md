# Deterministic LPN Benchmarks
Code for benchmarking Deterministic LPN instances with different diffuser functions on two platforms. For each subfolder, the diffuser functions are in `common` (Namely Simpira, Ascon-PRF, LightMAC), and `tests` contains the actual experiments to run benchmark. The only parameters to be varied are the length of LPN sample/ secret which is the macro `VECTOR_LENGTH` and the noise rate $\tau$ which is the macro `tau` (=$100\times\tau$ i.e. 33 for $\tau=0.33$, 1 for $\tau=0.01$ and so on). Our experiments are run for VECTOR_LENGTH = 512, 1024, 2048, 4096 and tau = 33, 10, 5, 1. In each subfolder we provide readme with more details
